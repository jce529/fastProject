# 탑 등반 액션 프로토타입
# Room Prefab 설계 문서 (개정판)

> 기획서 변경사항 반영 버전
>
> 주요 변경점
>
> - 구르기(Roll) 추가
> - 히트 프리즈(Hit-Freeze) 추가
> - 공격 방향 조준 시스템 추가
> - 시간정지 게이지 회복 방식 확정
> - 연속 처치 플레이 검증 필요
> - 회피 플레이 검증 필요

---

# 설계 목표

Room은 단순히 다른 모양의 맵이 아니다.

각 Room은 플레이어에게 특정한 질문을 던진다.

```text
싸울 것인가?
피할 것인가?

구를 것인가?
돌진할 것인가?

적을 죽일 것인가?
무시할 것인가?

게이지를 사용할 것인가?
아껴둘 것인가?
```

이러한 선택이 재미있는지 검증하는 것이 목적이다.

---

# Room_Combat

## 컨셉

순수 전투

## 플레이 경험

플레이어는 적을 발견하면 자연스럽게 공격 버튼을 사용하게 된다.

슬로우 모션과 돌진 공격의 기본 재미를 가장 직접적으로 경험할 수 있는 방이다.

## 검증 목표

```text
공격 버튼 사용 빈도
슬로우 모션 만족도
직선형 공격 만족도
부채꼴형 공격 만족도
자동 타겟팅 만족도
히트 프리즈 만족도
```

## 특징

```text
넓은 공간
장애물 거의 없음
전투 중심
이동 난이도 낮음
```

## 핵심 질문

```text
공격 자체가 재미있는가?
```

# Room_Hunt

## 컨셉

사냥터

## 플레이 경험

다양한 높이에 적이 배치된다.

플레이어는 방향을 조준하여 원하는 적을 노려야 한다.

## 검증 목표

```text
조준 정확도
방향 지정 만족도
수직 전투
타겟 선택 만족도
```

## 특징

```text
고저차 존재
적 밀집
연속 처치 가능
```

## 핵심 질문

```text
원하는 적을 정확히 공격할 수 있는가?
```

# Room_Ladder

## 컨셉

수직 이동

## 플레이 경험

전투보다 위로 올라가는 것이 중요하다.

등반 자체가 목표가 된다.

## 검증 목표

```text
사다리 조작감
수직 이동 속도
등반 템포
```

## 특징

```text
적 거의 없음
긴 사다리
단순 구조
```

## 핵심 질문

```text
등반 자체가 답답하지 않은가?
```

# Room_LadderDanger

## 컨셉

위험한 등반

## 플레이 경험

사다리를 오르는 동안 적의 압박을 받는다.

플레이어는 순간적으로 선택해야 한다.

```text
적을 죽일까?
구르기로 피할까?
무시하고 올라갈까?
```

## 검증 목표

```text
등반 중 전투
원거리 적 대응
구르기 활용
판단 속도
```

## 특징

```text
사다리 존재
근접 적 존재
원거리 적 존재
압박감 높음
```

## 핵심 질문

```text
등반과 전투가 자연스럽게 섞이는가?
```

# Room_Fall

## 컨셉

실수 유도

## 플레이 경험

플레이어는 낙사를 경험하게 된다.

복귀 시스템이 얼마나 스트레스 없이 작동하는지 검증한다.

## 검증 목표

```text
낙사 복귀
복귀 무적
좌절감 여부
재도전 의지
```

## 특징

```text
깊은 낙사 구역
좁은 발판
정밀 점프 요구
```

## 핵심 질문

```text
낙사가 짜증이 아닌 학습으로 느껴지는가?
```

# Room_Sniper

## 컨셉

저격수 제거

## 플레이 경험

멀리 있는 원거리 적이 플레이어를 지속적으로 압박한다.

플레이어는 위험 대상을 우선 제거해야 한다.

## 검증 목표

```text
슬로우 모션 활용
우선 타겟 선정
돌진 거리 체감
조준 정확도
```

## 특징

```text
넓은 시야
원거리 적 중심
전투 압박 높음
```

## 핵심 질문

```text
위험한 적을 먼저 제거하는 재미가 있는가?
```

```text
빠르게 달리는 것이 재미있는가?
```

# Room_Chase

## 컨셉

도망치기

## 플레이 경험

적이 너무 많아 싸우는 것보다 피하는 것이 효율적이다.

기획서 핵심인

```text
적을 전부 죽일 필요는 없다
```

를 가장 잘 보여준다.

## 검증 목표

```text
전투 생략 플레이
회피 플레이
출구 집중 플레이
```

## 특징

```text
적 다수
회피 중심
빠른 진행
```

## 핵심 질문

```text
싸우지 않아도 재미있는가?
```

# Room_Dodge

## 컨셉

회피 특화

## 플레이 경험

구르기 사용을 강하게 요구한다.

```text
공격 예고
↓
구르기 회피
↓
반격
```

## 검증 목표

```text
구르기 만족도
무적 프레임 체감
공격과 회피 균형
```

## 특징

```text
원거리 적 위주
좁은 공간
반응 속도 요구
```

## 핵심 질문

```text
구르기 자체가 재미있는가?
```

# Room_Chain

## 컨셉

연속 처치

## 플레이 경험

적들이 연속적으로 배치된다.

플레이어는 게이지를 회복하며 끊임없이 공격을 이어간다.

```text
처치
↓
게이지 회복
↓
다음 적 탐색
↓
연속 처치
```

## 검증 목표

```text
게이지 회복 체감
연속 전투 재미
공격 리듬감
```

## 특징

```text
적 밀집
전투 중심
빠른 템포
```

## 핵심 질문

```text
연속 처치가 쾌감을 주는가?
```

# Room_Recovery

## 컨셉

게이지 관리

## 플레이 경험

적이 적게 등장한다.

플레이어는 게이지 사용 여부를 고민하게 된다.

```text
지금 사용할까?
아껴둘까?
```

## 검증 목표

```text
게이지 관리
슬로우 의존도
자원 사용 판단
```

## 특징

```text
적 적음
긴 이동 구간
전투 빈도 낮음
```

## 핵심 질문

```text
게이지 관리가 전략으로 작동하는가?
```

# Room_Mixed

## 컨셉

실전 테스트

## 플레이 경험

모든 요소가 혼합되어 있다.

플레이어는 순간적으로 여러 결정을 내려야 한다.

```text
싸울까?
도망칠까?
구를까?
돌진할까?
원거리 적부터 제거할까?
사다리를 탈까?
```

## 검증 목표

```text
전체 게임 루프 검증
플레이 흐름 검증
난이도 체감
장기 플레이 가능성
```

## 특징

```text
플랫폼
사다리
낙사 구역
근접 적
원거리 적
구르기 활용
```

## 핵심 질문

```text
게임 전체가 재미있는가?
```

# 최종 목표

모든 Room은 플레이어에게 하나의 질문을 던져야 한다.

```text
싸울 것인가?

피할 것인가?

구를 것인가?

돌진할 것인가?

게이지를 사용할 것인가?

아껴둘 것인가?
```

이 질문에 답하는 과정 자체가 재미있다면 프로토타입은 성공이다.
