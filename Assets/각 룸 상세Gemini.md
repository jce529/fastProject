# [GSD Action Plan] Bleeding Spring (혈연) - 2D 횡스크롤 맵 블록아웃 설계도

> **목적:** 2D 횡스크롤 시점(Side-View)에 맞춘 Room 프리팹 구조화 및 핵심 기믹 검증
> **개발 환경:** Unity / C# 기반 콜라이더 및 트리거 테스트 

---

## 1. Room_Combat (순수 전투)
* **시점:** 2D 횡스크롤 평면
* **검증 목적:** 돌진 공격 사거리, 히트 프리즈, 무기 변형 타격감 확인

```text
[Wall]                                                        [Wall]
  |                                                              |
  |         [E: 근접]             [ P ]             [E: 근접]        |
  |             >───────── (돌진/타격 범위) ─────────<               |
====================================================================
[ ENT ]                                                     [ EXIT ]

```

* **구현 상세:** 장애물이나 고저차가 없는 평평한 아레나. 물보라 이펙트를 동반한 돌진 공격과 무기 변형 기믹의 최대 사거리가 중앙 캐릭터(P)에서 적(E)에게 정확히 닿도록 X축 거리를 조절합니다.

---

## 2. Room_Hunt (사냥터)

* **시점:** 2D 횡스크롤 다층 구조
* **검증 목적:** Y축 타겟팅 및 수직 방향 공격의 직관성

```text
                                                       [ EXIT ]
                           +---------+                 ========
                           |  [E]    |
       [E]           +-----+         +-----+             
  +---------+        |                     |      [E]
  |         |        |                     +---------+
==+         +========+                               +=========
[ ENT ]

```

* **구현 상세:** 위층, 아래층 등 다양한 고도에 플랫폼을 배치합니다. 점프 중 상/하단 방향 키 입력과 공격 버튼을 조합해 공중에서 적을 노리는 상하 조준 보정 로직을 집중적으로 테스트합니다.

---

## 3. Room_Ladder (수직 이동)

* **시점:** 2D 횡스크롤 수직 샤프트
* **검증 목적:** 사다리 조작감 및 수직 등반 템포

```text
===================== [ 천 장 / EXIT ] =====================
                      |  |
                      |  | 
                      |  | (사다리)
                      |P |
                      |  |
                      |  |
===================== [ 바 닥 / ENT ] =====================

```

* **구현 상세:** 적이나 복잡한 구조 없이 길게 뻗은 사다리만 존재합니다. 등반 애니메이션 속도와 키 입력 반응성이 답답하지 않고 쾌적한지 기본 이동 스크립트를 점검합니다.

---

## 4. Room_LadderDanger (위험한 등반)

* **시점:** 2D 횡스크롤 수직형 교전 구역
* **검증 목적:** 등반 중 원거리 공격 회피 및 전투 전환

```text
===================== [ 천 장 / EXIT ] =====================
                      |  |
  [공중 플랫폼]       |  |
  +---------+         |  |
  | [E:저격] | ---->>  |P | (발사체 타격 위협)
  +---------+         |  |
                      |  |       [중간 발판]
                      |  |       +---------+
                      |  |       | [E:근접] |
                      |  |       +---------+
===================== [ 바 닥 / ENT ] =====================

```

* **구현 상세:** 사다리를 오르는 도중 날아오는 발사체를 횡방향 점프로 피하거나, 수분 게이지를 소모해 적 방향으로 순간 돌진하는 등반 중 파생 액션을 강제합니다.

---

## 5. Room_Gap (점프 챌린지)

* **시점:** 2D 횡스크롤 플랫폼
* **검증 목적:** 기본 점프 체공 시간 및 공중 횡이동 제어

```text
                                                      [ EXIT ]
                                                      ========
            (Jump)                    (Jump)
[ ENT ]   ~~>             +====+    ~~>             +====+
=======  /               /      \  /               /
      +==+              /        +=+              /
               [ K I L L    Z O N E ] 

```

* **구현 상세:** 적을 배제하고 오직 간격이 넓은 플랫폼들만 배치합니다. 이동 벡터와 중력 값을 조절하여 공중 조작감이 매끄러운지 확인합니다.

---

## 6. Room_Fall (실수 유도)

* **시점:** 2D 횡스크롤 좁은 발판
* **검증 목적:** 낙사 트리거(Kill Z) 작동 및 복귀 무적 프레임

```text
                                                       [ EXIT ]
                                                       ========
               (Dash/Roll)           (Dash/Roll)      /
[ ENT ]      ~~>             +====+ ~~>             +==
=======     /                |    |                 |
      |    |                 |    |                 |
      [ K I L L    Z O N E ] (낙사 구역)

```

* **구현 상세:** 기본 점프만으로는 절대 닿지 않는 좁은 발판. 공중 돌진이나 구르기를 강제하며, 낙사 시 직전 발판으로 즉시 텔레포트 시켜 좌절감 없이 재도전하게 만드는 복귀 루틴을 테스트합니다.

---

## 7. Room_Sniper (저격수 제거)

* **시점:** 2D 횡스크롤 긴 복도
* **검증 목적:** 슬로우 모션 활용 및 돌진 거리 체감

```text
                                                 [고지대/EXIT]
                                                   +----+
                                                   | [E]|
  (엄폐물)                                         |    |
[ ENT ] =+             [E:근접]            [E:근접] |    |
=========+=========================================+====+
          <---------------- (사격 예고 선) ---------------- 

```

* **구현 상세:** 화면 끝에 위치한 저격수가 긴 직선형 레이저(사격 예고)를 조준합니다. 플레이어는 타이밍에 맞춰 슬로우 모션을 켜거나 무적 구르기로 탄환을 뚫고 들어가 우선순위 타겟을 제거해야 합니다.

---

## 8. Room_Stair (속도 런)

* **시점:** 2D 횡스크롤 경사로
* **검증 목적:** 슬로프(Slope) 이동 속도 및 연속성
* **구현 상세:** 가파른 계단이나 비탈길이 연속으로 이어집니다. 평지와 동일한 속도감이 유지되도록 캐릭터 컨트롤러의 최대 등반 각도(Max Slope Angle)와 마찰력을 점검합니다.

---

## 9. Room_Crossroad (경로 선택)

* **시점:** 2D 횡스크롤 상하 분기
* **검증 목적:** 위기 상황에서의 경로 선택 직관성

```text
                      (경로 A)  [E]  [E]  [E] 
                 +=============================+
                /                               \
[ ENT ] =======+                                 +======= [ EXIT ]
                \                               /
                 +====+      +====+      +====+
                      (경로 B) [낙사 구역]

```

* **구현 상세:** 위쪽은 적이 밀집된 전투 경로, 아래쪽은 낙사 위험이 있는 플랫폼 경로입니다. 현재 체력과 게이지 상태에 따라 플레이어가 자발적으로 경로를 선택하도록 유도합니다.

---

## 10. Room_Chase (도망치기)

* **시점:** 2D 횡스크롤 일직선형 도주로
* **검증 목적:** 전투 생략 플레이 및 회피 성능 한계
* **구현 상세:** 플레이어의 뒤에서 절대 죽일 수 없는 거대한 적이나 다수의 무리가 쫓아옵니다. 오직 구르기 무적 판정과 공중 대시만을 이용해 출구까지 도달해야 하는 레벨입니다.

---

## 11. Room_Dodge (회피 특화)

* **시점:** 2D 횡스크롤 좁은 골목
* **검증 목적:** 구르기의 무적 프레임 성능 및 입력 지연

```text
[ 천 장 ] ====================================================
                                                    [ EXIT ]
          <---- (거대 파동 공격 / 맵 전체 덮음) -----  [E]
[ ENT ]                                             [보스형]
[ 바 닥 ] ====================================================

```

* **구현 상세:** 피할 공간(점프/우회)이 전혀 없습니다. 적의 공격 판정 시간이 플레이어의 이동 속도보다 길게 설정되어, 오직 정확한 타이밍의 '구르기'로만 판정을 통과할 수 있습니다.

---

## 12. Room_Chain (연속 처치)

* **시점:** 2D 횡스크롤 계단형 밀집 구역
* **검증 목적:** 돌진 게이지 반환 로직 및 연속 타격 리듬감

```text
                                              [ EXIT ]
                                              ========
                                         [E] +
                                     [E] +===+
                                 [E] +===+
                             [E] +===+
[ ENT ] =========================+

```

* **구현 상세:** 체력이 1인 적들을 플레이어의 돌진 사거리에 딱 맞춰 계단식으로 배치합니다. 적 처치 시 시간정지/돌진 게이지가 즉시 회복되어, 버튼 연타만으로 출구까지 끊기지 않고 썰고 올라가는 쾌감을 검증합니다.

---

## 13. Room_Recovery (게이지 관리)

* **시점:** 2D 횡스크롤 긴 이동 구역
* **검증 목적:** 자원 소모와 보존에 대한 판단 유도
* **구현 상세:** 적이 거의 등장하지 않는 맵. 움직이는 엘리베이터나 긴 이동 발판이 존재합니다. 이전 방에서 소모된 게이지를 언제 채울지, 혹은 돌발 함정을 넘기 위해 아껴둘지 전략적 관리를 테스트합니다.

---

## 14. Room_Mixed (실전 테스트)

* **시점:** 2D 횡스크롤 복합 구조
* **검증 목적:** 전체 액션 루프(싸움, 회피, 자원 관리) 종합 검증

```text
                                                 [ EXIT ]
                                                 ========
                                                  [E] ↑ 
                                                  [E] | (Room_Chain)
                                                  [E] |  
                          +-------------------+   | | |
          (경로 A: 회피)  |    [E: 거대 몹]   |   ===+
[ ENT ] =================/ \==================/
  ||                     \
  || (경로 B: 플랫폼 점프) +====+         +====+
  ||                            \       /      \
[시작점]                         =======        ========= 
                               [ 낙사 구역 ]

```

* **구현 상세:** 경로 선택, 구르기, 점프 챌린지가 모두 포함되어 있으며, 합류점 이후에는 연속 처치(Chain)로 폭발적인 게이지 소모를 유도합니다. "싸울지 피할지"에 대한 플레이어의 모든 결정을 한 공간에서 테스트합니다.
