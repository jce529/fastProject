# Room Prototype Design Document — 최종본

> **목적:** 2D 횡스크롤 핵심 메카닉 검증을 위한 Action Mechanic Validation Room 설계
>
> 각 Room은 하나의 질문에 답한다. 프로토타입 단계에서는 여러 요소를 섞지 않는다.
>
> **리소스 명칭:** 크로노 게이지 (슬로우 모션 발동 리소스)

---

## 설계 원칙

각 Room은 플레이어에게 하나의 질문을 던진다.

```
공격이 재미있는가?
구르기가 재미있는가?
등반이 재미있는가?
회피가 재미있는가?
연속 처치가 재미있는가?
게이지 관리가 재미있는가?
```

---

## Room_Combat

**컨셉:** 순수 전투

**플레이 질문:**
```
공격 자체가 재미있는가?
```

**구조:**
```
[Wall]                                                        [Wall]
  |                                                              |
  |         [E: 근접]             [ P ]             [E: 근접]   |
  |             >───────── (돌진/타격 범위) ─────────<           |
====================================================================
[ ENT ]                                                     [ EXIT ]
```

**특징:**
- 넓은 평지, 장애물 없음, 낙사 없음
- 물보라 이펙트를 동반한 돌진 공격의 최대 사거리가 P에서 E에 정확히 닿도록 X축 거리 조절
- 근접 적 3~5마리

**검증 요소:**
```
공격 타격감
슬로우 모션
히트 프리즈
자동 타겟팅
```

---

## Room_Hunt

**컨셉:** 사냥터

**플레이 질문:**
```
원하는 적을 정확히 공격할 수 있는가?
```

**구조:**
```
                                                       [ EXIT ]
                           +---------+                 ========
                           |  [E]    |
       [E]           +-----+         +-----+             
  +---------+        |                     |      [E]
  |         |        |                     +---------+
==+         +========+                               +=========
[ ENT ]
```

**특징:**
- 고저차 존재, 다층 플랫폼
- 상층/중층/하층에 적 분산 배치 (각 1마리)

**검증 요소:**
```
조준 정확도
상향 공격
하향 공격
타겟 선택
```

---

## Room_Ladder

**컨셉:** 수직 이동

**플레이 질문:**
```
등반 자체가 답답하지 않은가?
```

**구조:**
```
===================== [ 천 장 / EXIT ] =====================
                      |  |
                      |  |
                      |# |
                      |# | (사다리)
                      |# |
                      |# |
                      |P |
                      |  |
===================== [ 바 닥 / ENT ] =====================
```

**특징:**
- 적 없음, 긴 사다리, 단순 구조

**검증 요소:**
```
사다리 조작감
수직 이동 속도
등반 템포
```

---

## Room_LadderDanger

**컨셉:** 위험한 등반

**플레이 질문:**
```
등반과 전투가 자연스럽게 섞이는가?
```

**구조:**
```
===================== [ 천 장 / EXIT ] =====================
                      |  |
  [공중 플랫폼]       |  |
  +---------+         |  |
  | [E:원거리]| ---->> |P | (발사체 위협)
  +---------+         |  |
                      |  |       [중간 발판]
                      |  |       +---------+
                      |  |       | [E:근접] |
                      |  |       +---------+
===================== [ 바 닥 / ENT ] =====================
```

**특징:**
- 원거리 적: 사다리 등반 중 발사체 위협
- 근접 적: 중간 발판에서 전투 강제
- 횡방향 점프 또는 크로노 게이지를 소모한 돌진으로 회피

**검증 요소:**
```
등반 중 전투
구르기 활용
크로노 게이지 소모 판단
판단 속도
```

## Room_Gap

**컨셉:** 점프 챌린지

**플레이 질문:**
```
이동 자체가 즐거운가?
```

**구조:**
```
                                                      [ EXIT ]
                                                      ========
            (Jump)                    (Jump)
[ ENT ]   ~~>             +====+    ~~>             +====+
=======  /               /      \  /               /
      +==+              /        +=+              /
               [ K I L L    Z O N E ]
```

**특징:**
- 적 없음, 넓은 점프 간격, 낙사 가능

**검증 요소:**
```
점프 감각
공중 제어
이동 만족도
```

---

## Room_Fall

**컨셉:** 실수 유도

**플레이 질문:**
```
낙사가 좌절이 아닌 학습으로 느껴지는가?
```

**구조:**
```
                                                       [ EXIT ]
                                                       ========
               (Dash/Roll)           (Dash/Roll)      /
[ ENT ]      ~~>             +====+ ~~>             +==
=======     /                |    |                 |
      |    |                 |    |                 |
      [ K I L L    Z O N E ] (낙사 구역)
```

**특징:**
- 기본 점프만으로는 절대 닿지 않는 좁은 발판
- 공중 돌진 또는 구르기 강제
- 낙사 시 직전 발판으로 즉시 복귀해 좌절감 없이 재도전

**검증 요소:**
```
복귀 속도
스트레스 여부
재도전 의지
복귀 무적 프레임
```

---

## Room_Sniper

**컨셉:** 저격수 제거

**플레이 질문:**
```
위험한 적을 먼저 제거하는 재미가 있는가?
```

**구조:**
```
                                                 [고지대/EXIT]
                                                   +----+
                                                   | [E]|
  (엄폐물)                                         |    |
[ ENT ] =+             [E:근접]            [E:근접] |    |
=========+=========================================+====+
          <---------------- (레이저 예고선) ----------------
```

**특징:**
- 화면 끝 고지대의 원거리 적이 레이저 예고선으로 조준
- 플레이어는 슬로우 모션 타이밍을 맞추거나 구르기로 탄환을 뚫고 우선순위 타겟 제거
- 근접 적이 전진하며 압박

**검증 요소:**
```
우선 타겟 선정
돌진 거리 체감
슬로우 모션 활용 타이밍
```

---

## Room_Stair

**컨셉:** 속도 런

**플레이 질문:**
```
빠르게 달리는 것이 재미있는가?
```

**구조:**
```
                                                  [ EXIT ]
                                                  ========
                                            ────
                                      ────
                                ────
                          ────
[ ENT ] ────
```

**특징:**
- 계단형 상승 구조, 연속 점프 유도
- 평지와 동일한 속도감 유지를 위해 Max Slope Angle / 마찰력 점검

**검증 요소:**
```
속도감
점프 연속성
경사면 이동 일관성
리듬감
```

---

## Room_Crossroad

**컨셉:** 경로 선택

**플레이 질문:**
```
선택하는 재미가 존재하는가?
```

**구조:**
```
                      (경로 A) [E]  [E]  [E]
                 +=============================+
                /                               \
[ ENT ] =======+                                 +======= [ EXIT ]
                \                               /
                 +====+      +====+      +====+
                      (경로 B) [낙사 위험]
```

**루트 비교:**

| | 경로 A (상층) | 경로 B (하층) |
|-|-------------|-------------|
| 위험 | 적 밀집 전투 | 낙사 위험 플랫폼 |
| 체력 소모 | 높음 | 낮음 |
| 처치 수 | 많음 | 적음 |
| 속도 | 빠름 | 느림 |

> **참고:** 추후 점수 시스템(빠름 + 체력 소모 적음 + 처치 수 많음 → 고득점) 연계 예정. 현재 프로토타입에서는 경로 선택 직관성 자체만 검증.

**검증 요소:**
```
경로 선택 직관성
위험과 이득의 가독성
플레이 스타일 차이 발생 여부
```

---

## Room_Chase

**컨셉:** 도망치기

**플레이 질문:**
```
싸우지 않아도 재미있는가?
```

**구조:**
```
[ ENT ]                                          [ EXIT ]
=========================================================
                                                        
 [거대 몹 / 절대 죽일 수 없음] >>>>>>>>>>>>> P >>>>>>
                                                        
=========================================================
```

**특징:**
- 뒤에서 절대 처치 불가능한 거대 적 또는 무리가 추격
- 오직 구르기 무적과 공중 돌진으로만 출구 도달
- 전투 시도 시 즉사 또는 무의미한 결과로 전투 포기를 유도

**검증 요소:**
```
전투 생략 플레이
회피 성능 한계
출구 집중 유도
```

---

## Room_Dodge

**컨셉:** 회피 특화

**플레이 질문:**
```
구르기 자체가 재미있는가?
```

**구조:**
```
[ 천 장 ] ====================================================

          <---- (거대 파동 공격 / 맵 전체 범위) -----  [E]
[ ENT ]                                             [보스형]
[ 바 닥 ] ====================================================
```

**특징:**
- 점프나 우회로가 전혀 없음
- 적의 공격 판정 시간 > 플레이어 이동 속도
- 오직 정확한 타이밍의 구르기로만 판정 통과 가능

**플레이 흐름:**
```
공격 예고
↓
구르기 회피 (타이밍 정확해야만 통과)
↓
반격 창 오픈
```

**검증 요소:**
```
구르기 만족도
무적 프레임 체감
반격 타이밍
```

---

## Room_Chain

**컨셉:** 연속 처치

**플레이 질문:**
```
연속 처치가 쾌감을 주는가?
```

**구조:**
```
                                              [ EXIT ]
                                              ========
                                         [E] +
                                     [E] +===+
                                 [E] +===+
                             [E] +===+
[ ENT ] =========================+
```

**특징:**
- 체력 1인 적들을 돌진 사거리에 맞춰 계단식 배치
- 처치 시 크로노 게이지 즉시 회복 → 버튼 연타로 끊기지 않고 위로 썰며 올라가는 흐름

**플레이 흐름:**
```
처치
↓
크로노 게이지 회복
↓
다음 적 탐색 (위쪽)
↓
연속 처치
```

**검증 요소:**
```
크로노 게이지 회복 체감
전투 리듬감
연속 처치 만족도
```

---

## Room_Recovery

**컨셉:** 게이지 관리

**플레이 질문:**
```
게이지 관리가 전략으로 작동하는가?
```

**구조:**
```
[E]                                              
──────────────                                   
                                                 
              (긴 이동 구간 / 움직이는 발판)     
                                                 
────────────────────────────────────────────────
                                                 
                                            [E]  
                                       ──────────
[ ENT ]                                  [ EXIT ]
```

**특징:**
- 전투 빈도 낮음, 이동 비중 높음
- 이전 룸에서 소모한 게이지를 언제 채울지 / 함정을 위해 아껴둘지 강제

**검증 요소:**
```
크로노 게이지 관리
자원 판단
슬로우 모션 의존도
```

## Room_Mixed

**컨셉:** 실전 테스트

**플레이 질문:**
```
게임 전체가 재미있는가?
```

**구조:**
```
                                                 [ EXIT ]
                                                 ========
                                                  [E] ↑ 
                                                  [E] | (Chain 구간)
                                                  [E] |  
                          +-------------------+   | | |
          (경로 A: 회피)  |    [E: 거대 몹]   |   ===+
[ ENT ] =================/ \==================/
  ||                     \
  || (경로 B: 플랫폼 점프) +====+         +====+
  ||                            \       /      \
[시작점]                         =======        =========
                               [ 낙사 구역 ]
```

**포함 요소:**
```
전투 / 연속 처치
등반
구르기
원거리 적
점프
낙사
경로 선택
```

**검증 요소:**
```
전체 게임 루프
플레이 흐름
난이도 체감
장기 플레이 가능성
```

## 개발 우선순위

### 1차 — 핵심 전투 검증
```
Room_Combat
Room_Fall
Room_LadderDanger
```

### 2차 — 회피 검증
```
Room_Sniper
Room_Dodge
```

### 3차 — 게이지 시스템 검증
```
Room_Chain
Room_Recovery   ← 크로노 게이지 구현 완료 확인됨 (ChronoGaugeController.cs)
```

### 4차 — 전체 루프 검증
```
Room_Hunt
Room_Stair
Room_Crossroad  ← 점수 시스템 연계 전 경로 직관성만 검증
Room_Chase
Room_Mixed
Room_Ladder     ← 등반 구현 후 독립 검증
```

---

## 최종 목표

모든 Room은 플레이어에게 질문을 던진다.

```
싸울 것인가?
피할 것인가?
구를 것인가?
돌진할 것인가?
크로노 게이지를 사용할 것인가?
아껴둘 것인가?
```

이 질문에 답하는 과정 자체가 재미있다면 프로토타입은 성공이다.
