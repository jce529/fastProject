교체할 본문:

```csharp
private (int melee, int ranged) GetEnemyCount(int floor)
{
    int total   = Mathf.Clamp(1 + (floor - 1) / 2, 1, 6);
    int ranged  = Mathf.Min(floor / 5, total / 2);
    int melee   = total - ranged;
    return (melee, ranged);
}
```

공식 동작 표:
| 층  | total | ranged | melee |
|-----|-------|--------|-------|
| 1   | 1     | 0      | 1     |
| 3   | 2     | 0      | 2     |
| 5   | 3     | 1      | 2     |
| 7   | 4     | 1      | 3     |
| 10  | 5     | 2      | 3     |
| 11+ | 6     | 2      | 4     |

summary 주석도 새 공식을 반영해 업데이트:
"D-07: 공식 기반 층 난이도. total = Clamp(1+(floor-1)/2, 1, 6). ranged = Min(floor/5, total/2)."
