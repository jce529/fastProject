# Quick Task 260617-0t2: Enemy Movement Animation FSM Wiring Summary

## What Was Done

### Task 1: MeleeEnemyAnimator.controller

Walk/Run 상태 분리 및 isChasing 파라미터 추가.

- `isChasing` Bool 파라미터 추가 (m_AnimatorParameters)
- Walk state motion: 기존 guid 교체 -> SwordWalk.anim (`0004225bdb14e3a49a6084f30afada60`)
- Run state (fileID: 4500000000000000030) 신규 추가 — SwordRunAltGrip.anim (`ff8716fd498244242b1cd19d8d5ef63b`)
- Idle->Walk 전환 조건: isMoving=true AND isChasing=false
- Idle->Run 전환 조건: isMoving=true AND isChasing=true
- Walk->Run 전환 조건: isChasing=true
- Run->Idle 전환 조건: isMoving=false
- Run->Walk 전환 조건: isChasing=false
- 모든 전환 duration = 0 유지 (ROADMAP Stack Constraint)

### Task 2: MeleeEnemy.cs

- `private Animator _animator;` 필드 추가 (Runtime refs 섹션)
- `Awake()`: `_animator = GetComponent<Animator>();` 캐시
- `UpdateIdle()`: `_rb.MovePosition(...)` 이후 `isMoving=true, isChasing=false` 구동
- `UpdateChase()`: `_rb.MovePosition(...)` 이후 `isMoving=true, isChasing=true` 구동
- `TelegraphAndAttack()`: `_state = Telegraph` 이후 `isMoving=false, isChasing=false` 구동
- `OnPlayerDied()`: `_state = Idle` 이전 `isMoving=false, isChasing=false` 구동
- `OnDashHit()` 및 `TelegraphAndAttack()`: `GetComponent<Animator>()` 직접 호출 -> `_animator` 캐시로 교체

### Task 3: RangedEnemyAnimator.controller + RangedEnemy.cs

**RangedEnemyAnimator.controller:**
- `isMoving` Bool 파라미터 추가
- Walk state (fileID: 4500000000000000040) 신규 추가 — GunWalk.anim (`a26a4fb5d01813e4493a7d70cc8c419c`)
- Idle->Walk 전환: isMoving=true
- Walk->Idle 전환: isMoving=false
- Idle state m_Transitions에 Idle->Walk 전환 추가

**RangedEnemy.cs:**
- `private Animator _animator;` 필드 추가
- `Awake()`: `_animator = GetComponent<Animator>();` 캐시
- `UpdateIdle()` patrol 분기: `isMoving=true`; else 분기: `isMoving=false`
- `UpdateChase()` 첫 줄: `isMoving=false` (Chase 상태는 이동 없음)
- `TelegraphAndFire()`: `_state = Telegraph` 이후 `isMoving=false`
- `OnPlayerDied()`: `isMoving=false` 추가
- `GetComponent<Animator>()` 직접 호출 2개 모두 `_animator` 캐시로 교체
