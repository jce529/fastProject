## What Was Built

### UpdateIdle() 변경
- 기존: `float newX = pos.x + dir * speed * dt; MovePosition(newX, rb.y);`
- 변경: `rb.linearVelocity = new Vector2(_patrolDir * patrolSpeed, rb.linearVelocity.y);` + `FlipSprite`
- 순찰 범위 반전 로직은 `transform.position.x - _spawnPosition.x` 기준으로 동일 유지

### UpdateChase() 변경
- 기존: `Vector2 dir = (player - pos).normalized; MovePosition(pos + dir * speed * dt);`
- 변경: `float dirX = Mathf.Sign(player.x - pos.x); rb.linearVelocity = new Vector2(dirX * chaseSpeed, rb.linearVelocity.y);` + `FlipSprite(dirX)` + `TryJump(dirX)`

### 새 Inspector 필드
- `jumpForce = 8f` — 점프 초속
- `wallCheckDist = 0.4f` — 앞 벽 감지 Ray 거리
- `gapCheckDist = 0.6f` — 바닥 끊김 감지 수평 offset

### 새 헬퍼 메서드
- `TryJump(float moveDir)` — IsGrounded() 이고 WallAhead 또는 GapAhead 시 Y velocity = jumpForce
- `IsGrounded()` — 발 아래 0.15f Raycast (Default/Ground/Platform)
- `WallAhead(float)` — 이동 방향 앞 wallCheckDist Raycast
- `GapAhead(float)` — 발 앞 gapCheckDist 지점 아래 0.5f Raycast; 바닥 없으면 true
- `FlipSprite(float)` — `_sr.flipX = dirX < 0f` (Awake 캐시 필드 사용)
