Start() 메서드를 다음 로직으로 교체한다:

1. using System.Collections.Generic 추가 (파일 상단)

2. Start() 수정:
   - enemies != null && enemies.Length > 0 이면 기존 정적 캐싱 유지 (IEnemy[] _enemyCache 빌드)
   - else (배열 비어있음) → GetComponentsInChildren<MonoBehaviour>(includeInactive: true)로
     transform 기준 자동 탐색, IEnemy 구현체만 List<IEnemy>에 수집 후 _enemyCache에 할당
   - _enemyCache가 null이거나 Length == 0이면 즉시 Activate() 호출 (적 없음 = 이미 클리어)

3. Update() 조건은 변경하지 않는다 (_activated || _enemyCache == null || _enemyCache.Length == 0 → return)
   — Activate() 즉시 호출 후 _activated=true가 세팅되므로 Update()는 아무 작업도 안 함

최종 Start() 구조:
```csharp
private void Start()
{
    if (targetObject != null)
        targetObject.SetActive(false);

    if (enemies != null && enemies.Length > 0)
    {
        // 정적 캐싱 (에디터에서 직접 연결한 경우)
        _enemyCache = new IEnemy[enemies.Length];
        for (int i = 0; i < enemies.Length; i++)
        {
            if (enemies[i] != null)
                _enemyCache[i] = enemies[i].GetComponent<IEnemy>();
        }
    }
    else
    {
        // 동적 탐색 (FloorSpawner 스폰 적 — includeInactive:true 필수)
        var found = new List<IEnemy>();
        foreach (MonoBehaviour mb in GetComponentsInChildren<MonoBehaviour>(true))
        {
            if (mb is IEnemy e)
                found.Add(e);
        }
        _enemyCache = found.ToArray();
    }

    // 적이 없으면 즉시 활성화
    if (_enemyCache == null || _enemyCache.Length == 0)
        Activate();
}
```

주의사항:
- Update()와 Activate()는 수정하지 않는다
- 기존 클래스 구조(필드 순서, 주석 헤더)를 유지한다
- using System.Collections.Generic은 파일 최상단 using 블록에 추가한다
