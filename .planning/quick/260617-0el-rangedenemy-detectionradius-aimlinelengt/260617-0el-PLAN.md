수정 후 UpdateChase():
```
private void UpdateChase()
{
    // 1. 플레이어 Transform 확보 (없으면 Idle로 복귀)
    if (_playerTransform == null)
    {
        FindPlayerTransform();
        if (_playerTransform == null) { _state = EnemyState.Idle; return; }
    }

    // 2. Chase 대기 중 감지 범위 이탈 → Idle 복귀
    if (!IsPlayerInRange(detectionRadius))
    {
        _playerTransform = null;
        _state = EnemyState.Idle;
        return;
    }

    // 3. 공격 트리거: aimLineLength 안에 진입했을 때만 텔레그래프 시작
    //    _telegraphCoroutine != null 가드: 매 프레임 호출되므로 중복 실행 방지
    if (IsPlayerInRange(aimLineLength) && _telegraphCoroutine == null)
    {
        _telegraphCoroutine = StartCoroutine(TelegraphAndFire());
    }
}
```

주의사항:
- IsPlayerInRange()는 내부에서 _playerTransform을 덮어쓰는 부수효과가 있다 (기존 구현 그대로). 순서(detectionRadius 먼저, aimLineLength 나중)를 반드시 지킨다.
- moveSpeed=0 기본값이면 Chase에서 이동 없음 — 기존 동작 유지. moveSpeed 관련 코드는 추가하지 않는다.
- TelegraphAndFire() 코루틴 끝에서 `_state = EnemyState.Idle; _telegraphCoroutine = null;` 가 이미 처리됨 — 수정 불필요.
- 클래스 상단 주석의 "Risk 6 mitigation" 설명은 더 이상 정확하지 않으나, 이번 PR 범위에서 주석 편집은 최소화한다. 필요하다면 해당 줄만 수정:
