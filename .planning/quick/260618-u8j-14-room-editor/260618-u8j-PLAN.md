## 공통 헬퍼

```
const int PLATFORM_LAYER = 9;   // TagManager: Platform
const float TILE = 1f;          // 1 Unity unit = 1 game tile
Sprite uiSprite = AssetDatabase.GetBuiltinExtraResource<Sprite>("UI/Skin/UISprite.psd");
```

마커 GameObject 생성 공통 메서드:
- CreateMarker(parent, name, position) → new GameObject(name), transform.SetParent, transform.localPosition 설정, 반환
- CreatePlatform(parent, name, pos, width, height) → GameObject, BoxCollider2D(size=width×height), SpriteRenderer(sprite=uiSprite, size=width×height), layer=PLATFORM_LAYER
- CreateKillZone(parent, name, pos, width, height) → GameObject, BoxCollider2D(size, isTrigger=true), FallZoneTrigger 컴포넌트 추가
- SavePrefab(root, roomName) → PrefabUtility.SaveAsPrefabAsset(root, $"Assets/Prefabs/Rooms/{roomName}/{roomName}.prefab"), DestroyImmediate(root)

## 좌표 기준

- 룸 중심 = (0, 0)
- ENT 마커: 룸 좌측 가장자리 (x=-halfWidth, y=0)
- EXIT 마커: 룸 우측 가장자리 (x=+halfWidth, y=0) — 수직 룸은 y=+halfHeight
- Platform y=0 이 바닥 기준선. 플랫폼 객체 위치는 플랫폼 중심점.
- KillZone: 바닥(y=0) 아래 y=-3, 폭은 룸 전체 폭, height=2

## 구현 요구사항

1. MenuItem 어트리뷰트: `[MenuItem("Fast/Build Room Prefabs")]`
2. 각 룸은 별도 static 메서드 `BuildRoom_{RoomName}()` 로 분리, Run()에서 순서대로 호출
3. BuildRoom_xxx() 시작 시 기존 프리팹 있으면 AssetDatabase.DeleteAsset() 후 재생성
4. 모든 Platform GameObject의 layer는 PLATFORM_LAYER(9)
5. KillZone GameObject에는 반드시 FallZoneTrigger 컴포넌트 추가 (`AddComponent<FallZoneTrigger>()`)
6. ENT/EXIT 마커는 빈 GameObject (콜라이더 없음)
7. EnemySpawn 마커는 빈 GameObject (콜라이더 없음) — 이름 형식: "EnemySpawn_0", "EnemySpawn_1"... (단 BossChaseSpawn, BossDodgeSpawn, MixedBossSpawn은 해당 이름 사용)
8. 룸 루트 GameObject 이름 = 룸 이름 (예: "Room_Combat")
9. SpriteRenderer size 설정 시 `spriteRenderer.size = new Vector2(width, height)` 사용 (DrawMode = Sliced 필요)
   - `spriteRenderer.drawMode = SpriteDrawMode.Sliced`를 반드시 size 설정 전에 적용
10. Run() 완료 후 `AssetDatabase.SaveAssets(); AssetDatabase.Refresh();` 호출
11. 각 룸 완료 시 `Debug.Log($"[RoomPrefabBuilder] {roomName} built at Assets/Prefabs/Rooms/{roomName}/{roomName}.prefab");`
12. using 문: UnityEditor, UnityEngine, UnityEditor.SceneManagement (필요 시)
