**Room_Combat 제작 (1층 고정 — 가장 단순한 평지)**

1. Hierarchy에서 우클릭 → Create Empty → 이름: `Room_Combat`
2. Transform.Position = (0, 0, 0)

3. `Room_Combat` 우클릭 → Create Empty Child → 이름: `Platforms`

4. `Platforms` 우클릭 → 2D Object > Sprite → 이름: `Ground`
   - SpriteRenderer의 Sprite: `Square` (Built-in) 또는 흰색 직사각형 스프라이트
   - Transform.Position = (0, 0, 0), Scale = (20, 1, 1)  (너비 20유닛, 높이 1유닛)
   - BoxCollider2D 추가: Size = (20, 1)
   - Layer = `Platform` (드롭다운에서 선택)

5. `Room_Combat` 우클릭 → Create Empty Child → 이름: `RoomExit`
   - Transform.Position = (0, _roomHeight - 1, 0) 에 배치  ← 방 최상단
     예: _roomHeight=18이면 Position.y = 17
   - Add Component → `RoomExit` 스크립트
   - Add Component → `BoxCollider2D`
     - Is Trigger = true (체크)
     - Size = (20, 1)  (방 전체 너비)

6. `Room_Combat` 선택 → Project 창의 `Assets/Prefabs/Rooms/Room_Combat/` 폴더로 드래그
   → "Create Prefab" 클릭 → `Room_Combat.prefab` 생성 확인
   → Hierarchy에서 `Room_Combat` 오브젝트 Delete
