<objective>
Unity Editor에서 직접 플레이해 Phase 2 핵심 메카닉을 수동으로 검증한다.
자동화 테스트 없음 — 에디터 Play 모드에서 각 요구사항을 직접 눈으로 확인한다.
상세 체크리스트는 02-04-EDITOR-GUIDE.md 참조.
</objective>

<design_notes>
## 공격 타입 선택 방식
- 오버레이 팝업(버튼 누를 때 나타나는 UI) 방식 → 폐기
- 화면 내 고정된 선택 존(zone)으로 대체: 항상 노출되어 있고, 손가락을 그 영역 안에서 이동하면 공격 타입이 바뀜

## 슬로우 모션 트리거 & 종료
- 트리거: 공격 버튼 누르는 순간 (기존: 타입 선택 완료 후)
- 종료: 타임아웃(최대 지속시간 경과) 또는 버튼 뗌

## 버튼 릴리스 분기
- 적 있음 → 대시 처치 (기존 동작 유지)
- 적 없음 → 검 휘두르기 + 이동 불가 (기존 "원위치 복귀" 대체)

## 구르기
- 쿨다운: 0.8s → 1s 로 변경
- 추가 제약: 구르기 도중 방향 전환 불가 (입력 방향 고정)
</design_notes>

<task id="02-04-01" title="ATCK-01/02: 공격 타입 선택 존 에디터 검증" type="checkpoint:human-verify">
  <how_to_test>
    1. Unity Editor에서 SampleScene 열기
    2. Play 버튼 클릭
    3. 화면에 공격 타입 선택 존이 표시되는지 확인
    4. 선택 존 내에서 마우스/터치를 이동하며 공격 타입 변경 여부 확인
  </how_to_test>
  <acceptance_criteria>
    - ATCK-01: 공격 버튼을 누르지 않아도 선택 존이 화면에 항상 노출됨
    - ATCK-02: 선택 존 내 이동 시 현재 공격 타입이 즉시 갱신됨 (UI 또는 로그로 확인)
  </acceptance_criteria>
</task>

<task id="02-04-02" title="ATCK-03/04/05/06 + FEEL-01: 전투 메카닉 에디터 검증" type="checkpoint:human-verify">
  <how_to_test>
    1. Play 모드에서 공격 버튼(Attack) 누르기
    2. 슬로우 모션 시작 및 타임아웃 자동 종료 확인
    3. 적 있는 상태에서 버튼 릴리스 → 대시 처치 확인
    4. 적 없는 상태에서 버튼 릴리스 → 검 휘두르기 + 이동불가 확인
    5. 처치 순간 hitFreeze 확인
  </how_to_test>
  <acceptance_criteria>
    - ATCK-03: 버튼 누르는 즉시 timeScale 감소 (슬로우 모션 시작)
    - ATCK-04: 버튼을 계속 누르고 있으면 일정 시간 후 자동으로 슬로우 해제
    - ATCK-05: 버튼 뗄 때 범위 내 적 있으면 가장 가까운 적에게 대시 → 처치
    - ATCK-06: 버튼 뗄 때 범위 내 적 없으면 제자리 검 휘두르기 애니 + 이동 불가 상태 (원위치 복귀 없음)
    - FEEL-01: 처치 순간 화면이 짧게 멈췄다가 재개 (hitFreeze ~75ms)
  </acceptance_criteria>
</task>

<task id="02-04-03" title="MOVE-03: 구르기 메카닉 에디터 검증" type="checkpoint:human-verify">
  <how_to_test>
    1. Play 모드에서 구르기 버튼(Shift) 입력
    2. 이동 거리 고정 여부 및 구르기 중 방향 전환 불가 확인
    3. 1초 쿨다운 내 재입력 시 발동 안 됨 확인
    4. 구르기 중 적 공격 무시 확인
  </how_to_test>
  <acceptance_criteria>
    - 구르기 시 고정 거리만큼 이동하고 중간에 방향이 바뀌지 않음
    - 무적 프레임 동안 적 공격이 무시됨
    - 1초 내 재입력 시 구르기 발동하지 않음 (쿨다운 1s)
    - 슬로우 모션 중 구르기가 정상 속도(unscaled)로 동작
  </acceptance_criteria>
</task>
