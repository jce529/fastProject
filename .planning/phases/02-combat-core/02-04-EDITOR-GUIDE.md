# Phase 02-04 에디터 플레이테스트 가이드

Phase 2 요구사항을 Unity Editor Play 모드에서 직접 확인하는 수동 체크리스트.

---

## 준비

1. Unity Editor에서 `Assets/Scenes/SampleScene` 열기
2. **Play** 버튼 클릭 (상단 중앙)
3. Game 뷰 포커스 확인

---

## ATCK-01: 공격 타입 선택

**실행:** 공격 버튼(마우스 클릭 또는 설정된 Attack 버튼) **누름 유지**

**확인:**
- [ ] 화면에 공격 타입 선택 오버레이가 나타난다
- [ ] Linear / Fan 중 선택 가능한 UI가 보인다
- [ ] 선택 전까지 오버레이가 유지된다

---

## ATCK-02: 슬로우 모션 발동

**실행:** 오버레이에서 공격 타입 선택 완료

**확인:**
- [ ] 선택 직후 게임 속도가 눈에 띄게 느려진다 (슬로우 모션)
- [ ] 플레이어 주변에 범위 표시(RangeDisplay 빔)가 나타난다
- [ ] 슬로우 모션 중에도 UI와 구르기는 정상 속도로 반응한다

---

## ATCK-03: 범위 내 적에게 대시

**준비:** DummyEnemy를 플레이어 범위(약 5유닛) 안에 배치

**실행:** 슬로우 모션 상태에서 공격 버튼 **뗌**

**확인:**
- [ ] 플레이어가 적 위치로 빠르게 이동한다
- [ ] 적이 즉시 제거된다 (DummyEnemy.IsAlive = false)
- [ ] 대시 후 시간이 정상 속도로 복귀한다

---

## ATCK-04: 범위 밖 whiff (락아웃)

**준비:** DummyEnemy를 범위 밖에 배치하거나 씬에서 제거

**실행:** 슬로우 모션 상태에서 공격 버튼 **뗌**

**확인:**
- [ ] 플레이어가 적에게 대시하지 않는다
- [ ] 짧은 lockout 후 원래 위치로 복귀한다
- [ ] 이 동안 다른 입력이 무시된다

---

## ATCK-05: 게이지 드레인 및 킬 보너스

**실행:** 공격 버튼을 2~3초 길게 누름 → 처치

**확인:**
- [ ] 버튼을 누르는 동안 화면의 게이지 UI가 감소한다
- [ ] 버튼을 떼면(처치 없이) 게이지가 서서히 회복된다
- [ ] 적 처치 시 게이지가 즉시 일부 회복된다

---

## FEEL-01: Hit-freeze

**실행:** 적을 대시로 처치

**확인:**
- [ ] 처치 순간 화면이 약 1프레임 멈추는 느낌이 든다 (hitFreeze ~75ms)
- [ ] 멈춤 후 정상적으로 게임이 재개된다
- [ ] 멈춤이 너무 길거나 짧지 않고 타격감이 있다

---

## MOVE-03: 구르기 (i-frame + 쿨다운)

**실행 A — i-frame 확인:**
1. 적이 공격하는 타이밍에 구르기(Shift) 입력
2. **확인:** 구르기 중 피격되지 않는다

**실행 B — 쿨다운 확인:**
1. 구르기 직후 즉시 다시 구르기 입력
2. **확인:** 두 번째 구르기가 발동하지 않는다 (0.8s 쿨다운)

**실행 C — 슬로우 모션 중 구르기:**
1. 슬로우 모션 발동 중 구르기 입력
2. **확인:** 구르기 속도가 게임 속도에 영향받지 않고 정상 동작한다
