  <how-to-verify>
    SampleScene(또는 DebugScene)에서 에디터 Play 후 아래 체크리스트를 확인한다.

    **[D-01/D-02/D-03 — 에임 리드 오프셋]**
    1. 평상시 이동 중에도(슬로우모션/조준 여부 무관) 마우스를 상하좌우로 움직이면 카메라가 마우스 방향으로 화면 크기의 약 15~25% 정도 은근히 선제 이동하는지 확인
    2. 리드 오프셋 반응(기본 SmoothDamp=0)이 눈에 띄는 입력 지연 없이 즉각적으로 느껴지는지 확인

    **[D-04 — 대시 중 리드 억제]**
    3. 대시-처치를 3회 이상 연속으로 체인하면서, 대시가 시작되는 순간 리드 오프셋이 즉시 0으로 사라지고, 대시가 끝난 직후 다시 자연스럽게 재개되는지 확인

    **[D-05/D-06/D-07/D-08 — 다이나믹 줌]**
    4. 거리/속도가 다른 여러 대시를 시도해, 줌아웃 정도가 대시 거리+속도에 비례해 달라지는지 확인
    5. 줌아웃(넓어짐)은 빠르게, 줌인(원상 복귀)은 느리게 느껴지는지 확인 (비대칭 댐핑)
    6. orthoSize가 시각적으로 약 9 이상으로 과도하게 벌어지지 않는지 확인 (룸 뷰 규격을 크게 벗어나지 않음)
    7. 히트프리즈(처치 순간 화면 정지)가 끝나는 즉시 줌인이 시작되는지 확인

    **[D-09/D-10 — 텐션 캐치업]**
    8. 플레이어를 화면 좌우 바깥쪽 25% 구간까지 의도적으로 빠르게 이동/유도해, 그 전(화면 중앙 50% 구간)에서는 카메라가 정적으로 추적만 하고 캐치업이 개입하지 않는지 확인
    9. 25% 경계를 넘어서면 캐치업이 개입하기 시작하고, 경계에서 더 멀어질수록(더 바깥으로 나갈수록) 캐치업 속도가 점점 더 강해지는지(선형이 아니라 가속하는 느낌인지) 확인

    **[히트스탑 셰이크 — 기존 기능 회귀 확인]**
    10. 처치 순간 카메라 셰이크가 여전히 정상 재생되는지 확인 (기존 Shake() 로직, 이 Phase에서 값 변경 없음)

    **[DebugSceneCameraBinder 회귀 — Phase 18.1 전례]**
    11. DebugScene.unity를 Play해 카메라가 여전히 보스 테스트 룸을 정상적으로 프레이밍하는지 확인 (SnapToRoom 배선 회귀 없음)

    **[CameraBound 클램프 — 양쪽 줌 극단]**
    12. Room_Combat 또는 Room_Dodge에서 평시(orthoSize 7)와 최대 줌(orthoSize 약 9) 양쪽 모두에서 카메라가 CameraBound의 `_size`를 벗어나 배경이 과도하게 노출되지 않는지 확인
