## 진입 흡입 이펙트 — 구현 방식

| Option | Description | Selected |
|--------|-------------|----------|
| Transform도 실제 이동 | 포탈 쪽으로 짧게 이동(MovePosition) — 핵심 불만을 근본적으로 해결 | |
| 시각 효과만 추가 | Transform 고정, 파티클/왜곡 셰이더만 추가 | (초기 질문, 자유 응답으로 대체됨) |

**User's free-text question:** "흡입으로 가면 중심이동이 아니라 빨려들어가야하는데 에디터로만 가능할까?"
**Claude's response:** 에디터(Animator/Timeline) 단독으로는 임의 위치의 포탈을 겨냥할 수 없음(포탈 위치가 매 룸마다 다름) — 코드가 목표 지점을 계산해야 함. 이 프로젝트의 기존 패턴(코드 코루틴 + Inspector `AnimationCurve`)을 따르는 하이브리드 방식을 제안.

**Follow-up — 새 스프라이트 없이 가능한가:**
**User's question:** "그니까 내 말은 별도의 스프라이트 수정없이 가능하냐고"
**Claude's response:** 가능 — (1) Transform만 조작(위치 나선+스케일 축소, 새 에셋 불필요, 권장), (2) URP 셰이더 기반 UV 소용돌이 왜곡(스프라이트 아트 불필요하나 신규 셰이더 작업 필요) 두 경로 제시.
**User's choice:** 2번(셰이더 기반) — "2번이 더 좋을것 같아"
**Notes:** 권장안(1번, Transform만)보다 기술적으로 더 큰 작업(신규 커스텀 셰이더 도입)을 사용자가 명시적으로 선택. CONTEXT.md D-01에 신규 기술 영역이라는 점을 명시.
