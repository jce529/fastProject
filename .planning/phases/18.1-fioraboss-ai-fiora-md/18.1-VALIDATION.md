## Manual-Only Verifications

| Behavior | Requirement | Why Manual | Test Instructions |
|----------|-------------|------------|-------------------|
| Room-boundary-relative dash sweep | D-04 | No automated test harness in project; visual/physical boss movement | Watch boss dash from one wall to the exact opposite wall, repeated across multiple passes. Boss reaches each wall without excessive overshoot/jitter; no hardcoded-coordinate room ever produces an out-of-bounds dash |
| Dash-count tiering by `_hitCount` | D-01/D-02 | RNG-based behavior, requires live observation across cycles | At `_hitCount=0`, count dash passes before Vulnerable (expect 3–5); land 2 hits, repeat (expect 4–6); land hits until `_hitCount=5`, repeat (expect 5–7). Sample ≥3 cycles per tier |
| Dash speed tiering | D-03/D-05 | Timing-based, no automated harness | Time a single wall-to-wall pass at each tier against known room width (28 units, `Room_BossFsmTest`). Tier 1 ≈ 1.75s, Tier 2 ≈ 1.4s, Tier 3 ≈ 1.17s (±small margin) |
| Wall dwell + reverse | D-06 | Visual timing feel, no automated harness | Watch boss pause briefly at each wall before reversing. Pause reads as a deliberate brief beat (0.1–0.2s), not instant bounce, not a long stall |
| First-dash-only telegraph | D-07 | Visual/animation state, no automated harness | Watch a full cycle from Vulnerable-end through all dash passes. Exclamation icon appears only before pass 1; passes 2..N have no icon |
| Continuous hitbox during dash | D-08 | Requires live player-boss collision, no automated harness | Stand in the boss's dash path during a mid-cycle pass (not just pass 1). Player dies (`TriggerDeath()`) if touched at any point during any pass |
| BOSS-03/04/05/06 regression | locked, unchanged | Full gameplay loop, no automated harness | Full 7-hit kill sequence; verify Vulnerable-only targeting; verify no progress UI; verify score bonus on kill only. Must match Phase 15's original verification map |
