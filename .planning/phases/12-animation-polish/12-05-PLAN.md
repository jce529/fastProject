  </what-built>
  <how-to-verify>
1. Unity Editor를 열고 컴파일이 완료될 때까지 기다린다 (Console에 에러가 없어야 함)
2. 상단 메뉴에서 `Fast > Phase12 > Patch Player Animator (Whiff+Roll Triggers)` 클릭
3. Console에서 `[PlayerAnimatorPatcher] Whiff/Roll 트리거+상태 패치 완료.` 로그를 확인한다 (Error 없어야 함)

5. Parameters 탭에서 `Whiff`(Trigger), `Roll`(Trigger)이 새로 추가되어 있는지 확인한다
6. 상태 그래프에서 `Whiff`라는 새 상태가 존재하고, Any State에서 `Whiff` 조건으로 들어오는 화살표가 있는지 확인한다
7. `Roll` 상태로 Any State에서 `Roll` 조건으로 들어오는 화살표가 추가로 존재하는지 확인한다 (기존 `IsRolling` bool 기반 전환은 그대로 남아있어야 한다)
8. 메뉴를 한 번 더 실행해도 Console에 에러 없이 "패치 완료" 로그만 다시 출력되고 파라미터/상태가 중복 생성되지 않는지 확인한다 (idempotency)
  </how-to-verify>
  <resume-signal>"완료" -- Whiff/Roll 파라미터+상태 확인됨. 또는 문제 설명.</resume-signal>
  <acceptance_criteria>

    - Whiff 상태가 존재하고 Any State에서 Whiff 조건 전환이 연결되어 있다
    - Roll 상태로의 Any State Roll 조건 전환이 추가되었고, 기존 IsRolling bool 전환은 그대로 유지된다
    - 메뉴 재실행 시 중복 생성 없이 정상 완료된다

8. Console에 관련 LogError가 없는지 확인한다
