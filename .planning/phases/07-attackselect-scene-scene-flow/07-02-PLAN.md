<task id="1" type="checkpoint:human-verify" gate="blocking">
  <name>AttackSelect.unity 씬 수동 제작 + Build Settings 설정</name>

  <read_first>
    - Assets/Scenes/MainMenu.unity — UI 구성 참고 (Canvas / Button 계층, 배경색)
    - Assets/Scripts/UI/AttackSelectController.cs — 연결할 메서드 이름 확인 (07-01에서 생성)
    - Assets/Editor/MainMenuSceneBuilder.cs — EventSystem(InputSystemUIInputModule) 설정 참고
    - ProjectSettings/EditorBuildSettings.asset — 현재 Build Settings 상태 확인
  </read_first>

  <what-built>
    - AttackSelectController.cs: OnLinearClicked() / OnFanClicked() (07-01 완료)
    - DeathScreenController.cs: LoadScene("AttackSelect") (07-01 완료)
  </what-built>

  <how-to-verify>
    **A. AttackSelect.unity 씬 제작 (단계별)**

    1. Unity Editor 메뉴 → File > New Scene → "Basic 2D" 또는 빈 씬 생성
    2. File > Save As → `Assets/Scenes/AttackSelect.unity` 저장
    3. 씬 계층(Hierarchy)에서 EventSystem 오브젝트 선택:
       - Inspector에서 StandaloneInputModule 컴포넌트가 있다면 Remove Component
       - Add Component → "Input System UI Input Module" 추가
       (없으면 GameObject > UI > Event System으로 새로 생성하고 위 단계 수행)
    4. Hierarchy → 우클릭 > UI > Canvas 생성 (없으면)
       - Canvas Inspector: Render Mode = "Screen Space - Overlay"
       - Canvas Scaler: UI Scale Mode = "Scale With Screen Size", Reference Resolution = 1920×1080
    5. Canvas 자식으로 빈 Panel 또는 Image 생성하여 배경 설정:
       - Image 컴포넌트 Color = (0.1, 0.1, 0.1, 1) (어두운 배경)
       - Rect Transform: Anchor = stretch/stretch, Left/Right/Top/Bottom = 0
    6. Canvas 자식으로 Button 생성 × 2:
       **LINEAR 버튼:**
       - 이름: "LinearButton"
       - Rect Transform: Width=400, Height=120, Position 중앙 기준 Y=+80
       - Button 자식 Text (TextMeshPro): "LINEAR"
       **FAN 버튼:**
       - 이름: "FanButton"
       - Rect Transform: Width=400, Height=120, Position 중앙 기준 Y=-80
       - Button 자식 Text (TextMeshPro): "FAN"
    7. 빈 GameObject 생성:
       - 이름: "AttackSelectController"
       - Add Component → AttackSelectController
    8. LINEAR 버튼 선택 → Inspector의 Button > On Click():
       - "+" 클릭하여 리스너 추가
       - 오브젝트 슬롯에 "AttackSelectController" 드래그
       - 함수 선택: "AttackSelectController > OnLinearClicked()"
    9. FAN 버튼도 동일하게:
       - "+" 클릭
       - 오브젝트 슬롯에 "AttackSelectController" 드래그
       - 함수 선택: "AttackSelectController > OnFanClicked()"
    10. Ctrl+S 로 씬 저장

    **B. Build Settings 설정**

    11. File > Build Settings 열기
    12. "Add Open Scenes" 클릭하거나 AttackSelect.unity를 드래그:
        - 현재 순서 확인: MainMenu.unity = 0, 기존 SampleScene 위치 확인
    13. 순서 조정 (드래그로):
        - Index 0: MainMenu.unity
        - Index 1: AttackSelect.unity (지금 추가한 씬)
        - Index 2: SampleScene.unity
    14. 창 닫기 (자동 저장)

    **C. 검증**

    15. File > Build Settings 다시 열어 순서 재확인:
        - MainMenu = 0, AttackSelect = 1, SampleScene = 2
    16. AttackSelect 씬에서 Play:
        - LINEAR 버튼 클릭: SampleScene 로드 시도 (성공 또는 씬 전환)
        - FAN 버튼 클릭: SampleScene 로드 시도
  </how-to-verify>

  <acceptance_criteria>
    - Assets/Scenes/AttackSelect.unity 파일이 디스크에 존재한다
    - Build Settings에서 AttackSelect.unity = index 1 (File > Build Settings 확인)
    - Build Settings에서 SampleScene.unity = index 2
    - AttackSelect 씬 Play 시 LINEAR 버튼 클릭 → SampleScene 로드됨 (Console 에러 없음)
    - AttackSelect 씬 Play 시 FAN 버튼 클릭 → SampleScene 로드됨
    - Unity Console에 컴파일 에러 없음
  </acceptance_criteria>

    3. MainMenu 씬 열기 (Assets/Scenes/MainMenu.unity 더블클릭)
    4. Play 시작

    **[1회차 — Linear 선택]**

    **[2회차 — Fan 선택]**

    13. 사망 → "다시 선택" → AttackSelect 복귀

    **[3회차 — 재확인]**
    14. LinearOrFan 중 하나 선택 → SampleScene → 사망 → "다시 선택" → AttackSelect 복귀

    **최종 체크**
