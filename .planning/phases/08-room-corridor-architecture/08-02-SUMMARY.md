# Phase 08 Plan 02: Corridor Builder Architecture Summary

**CorridorBuilder editor script producing 3 stepped Corridor prefabs (Flat/Up/Down) with RoomConnector ENT+EXIT markers and EnemySpawnPoint children for Phase 9 WorldGenerator chain assembly**

## Performance

- **Duration:** ~8 min
- **Started:** 2026-06-29
- **Completed:** 2026-06-29
- **Tasks:** 1
- **Files modified:** 1

## Accomplishments
- CorridorBuilder.cs: MenuItem "Fast/Phase8/Build Corridors" generates 3 Corridor prefabs under Assets/Prefabs/Corridors/
- Corridor_Flat: single floor (12x1), ENT at (-6,0), EXIT at (6,0) — same Y, straight run
- Corridor_Up: 3 ascending steps (Y=0/2/4), ENT at (-6,0), EXIT at (7,4) — 4-unit height gain
- Corridor_Down: 3 descending steps (Y=4/2/0), ENT at (-7,4), EXIT at (6,0) — 4-unit height drop
- Each Corridor has exactly 1 EnemySpawnPoint-tagged child above the highest reachable platform
- All ENT/EXIT children carry RoomConnector(Direction.Left/Right) — Phase 9 WorldGenerator can GetComponentsInChildren<RoomConnector>() immediately

## Files Created/Modified
- `Assets/Editor/CorridorBuilder.cs` — static editor class with MenuItem, 3 BuildCorridor_* methods, and CreatePlatform/CreateMarker/AddConnector/CreateSpawnPoint/SavePrefab helpers

## Decisions Made
- `AssetDatabase.Refresh()` called inside `SavePrefab()` after `Directory.CreateDirectory()` so Unity's asset database sees the new `Corridors/` subdirectory before `SaveAsPrefabAsset` — without this refresh the save silently fails on first run
- Tag assignment uses try/catch rather than pre-validation: `EnemySpawnPoint` is confirmed present in TagManager.asset, but defensive pattern keeps the tool safe if tag is ever renamed
- Prefabs are not committed as binary assets; the editor tool is the source of truth and re-running it is idempotent

## User Setup Required
After committing, open the Unity project and:
1. Wait for Unity to compile CorridorBuilder.cs (no errors expected)
2. Run menu: **Fast > Phase8 > Build Corridors**
3. Verify three prefabs appear in `Assets/Prefabs/Corridors/`:
   - `Corridor_Flat/Corridor_Flat.prefab`
   - `Corridor_Up/Corridor_Up.prefab`
   - `Corridor_Down/Corridor_Down.prefab`
4. Open any prefab — select ENT child (blue Gizmo sphere = Left), EXIT child (green = Right)
5. Select EnemySpawn_0 child — Inspector Tag field should show "EnemySpawnPoint"

## Known Stubs
- Corridor prefabs do not exist on disk yet — they are created when the editor menu is run in Unity. This is by design: the script is the source of truth. Phase 9 WorldGenerator cannot run until the menu has been executed at least once. Documented in User Setup Required above.
