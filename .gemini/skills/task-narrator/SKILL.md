# Task Narrator

이 스킬은 에이전트가 수행하는 모든 동작을 사용자에게 투명하게 공개하고, 현재 진행 상황을 명확하게 파악할 수 있도록 돕는 "중계" 역할을 합니다.

## 핵심 가이드라인

1. **도구 호출 전 설명 (Explain Before Acting)**:
   - 어떠한 도구(read_file, replace, run_shell_command 등)를 호출하기 직전에, 해당 도구를 사용하는 **구체적인 이유**와 **기대 결과**를 한글로 설명합니다.
   - 예: "현재 보스 스탯 시스템의 수치 오류를 수정하기 위해 `Assets/Enemy/NewBoss/Script/BossStatesSystem.cs` 파일을 읽어 내용을 확인하겠습니다."

2. **작업 단계 브리핑**:
   - 복잡한 작업(Phase 실행 등)을 수행할 때는 각 하위 작업(Task)에 진입할 때마다 현재 어느 단계를 수행 중인지 명시합니다.
   - 예: "[Step 1/3] 데미지 데이터 모델 생성을 시작합니다."

3. **결과 요약 (Optional)**:
   - 도구 실행 결과가 복잡하거나 중요한 변경사항이 있는 경우, 실행 후 무엇이 바뀌었는지 간략히 요약합니다.

## 출력 스타일
- 전문적이고 친절한 톤을 유지합니다.
- 불필요한 미사여구는 배제하고 **의도(Intent)**와 **상태(State)** 위주로 전달합니다.
- 모든 설명은 **한글**로 작성하는 것을 기본으로 합니다.

## 사용 예시

사용자: "보스 HP 소모 로직 수정해줘."

에이전트:
"보스 공격 시 HP가 소모되는 로직을 수정하기 위해 먼저 `WaterMonsterStats.cs` 파일을 분석하겠습니다."
(read_file 호출)

"분석 결과, 소모 수치가 5%로 고정되어 있습니다. 이를 3%로 하향 조정하기 위해 코드를 수정하겠습니다."
(replace 호출)

"수정이 완료되었습니다. 변경된 로직이 정상적으로 컴파일되는지 확인하기 위해 셸 명령어를 실행합니다."
(run_shell_command 호출)
